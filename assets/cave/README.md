# Cave meshes

Generated for this project by `tools/cave_gen.py` (signed distance fields plus
marching cubes). Original work, released under CC0 1.0 like the rest of the
original art. Each `.glb` has a `.json` next to it with the spawn point, torch
and crystal spots, rubble, open floor spots and map cells.

Regenerate with `python tools/cave_gen.py` (needs numpy, scikit-image, trimesh).
